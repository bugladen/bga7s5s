| `modules/php/cards/bas/_04cd07.php` | Pure dual-Forced CityEventCard (no Action/Reaction/State/JS). Reveal → each player draws (`EventCityCardAddedToLocation`). Shows: reveal gate without `cardInCity`, queued `createCardDrawnEvent`, and **not** early-returning when the location is uncontrolled (unlike Equal Claim — uncontrolled still means non-controllers qualify). |
| `modules/php/cards/bas/_04cd09.php` + `actions/Action_04cd09.php` + 3 state files | Continuous location refuse lock (Daichi-style, **not** a `CHALLENGE_TYPE`) **plus** Unlimited City Action: engage-or-discard cost → move this event card to another City location. Demonstrates: `RequiresPerformerSelected = false`, numeric cost-choice buttons, EVENTS hop after mid-action payment, `setUsed(false)` without `$playersUsed`, destination = any other city location (not adjacency), bas JS + `EventHandlers` hand-discard enable. |
| `modules/php/cards/bas/_04cd11.php` + `State_duskPhaseBegin04cd11.php` | **Interactive Forced** at beginning of Dusk: each eligible player must choose one of their characters here → heal a wound + stay Home. Demonstrates: `EventDuskPhaseBegin` + `cardInCity`, multi-player `createTransitionEvent` queue in `turn_order`, `DUSK_PHASE_BEGIN_EVENTS` registration (not High Drama), new stay-Home condition + `eventCheck` on `EventCardMoved`→Home (Penya path), no Pass / zombie auto-pick, bas JS character picker, heal via `createCharacterBeingHealedEvent` even at 0 wounds. |
| `modules/php/cards/_7s5s/_01177.php` | Older dusk stay-Home + choose character (Reaction/"may", Pass allowed, `states.7s5s.php` entry). Same `EventCardMoved` block + `HELPED_BY_PENYA` condition. Use `_04cd11` for modern Forced-must / State-class dusk wiring; keep `_01177` for the stay-Home eventCheck mechanics. |
| `modules/php/cards/faf/_03cd20.php` + `actions/Action_03cd20.php` + `reactions/Reaction_03cd20.php` | CityEventCard with a **Reaction-while-in-Home** (`EventPhasePlanningEnd`, multi-stage button-based picker — character → adjacent city → discard) AND a **Pressure-with-Finesse City Action** that puts the card back in the active player's Home on success.
