# Superstitious (03024) Implementation

## Card Details
- **Risk card** extending Risk, faction Eisen
- **Stats:** 1 Riposte, 1 Parry, 2 Thrust
- **Traits:** Flourish, Hubris, Faith
- **Wealth Cost:** 1
- **Text:** Maneuver: If the adversary is a Sorcerer or Monster • +2 Parry or +2 Thrust

## Implementation Plan

This is a simple conditional-choice maneuver:
1. **Gate:** adversary must be Sorcerer or Monster (checked in `isAvailableToPlayer`)
2. **Choice:** actor picks +2 Parry OR +2 Thrust via `actFromManeuverWithId`
3. **Effect:** apply chosen stat in `EventDuelCalculateManeuverValues` based on choice flag

### Why This Approach
- No cross-player interaction — only the maneuver player chooses
- No state persistence across rounds — the choice is made once, applied this round, then fresh on next round
- Uses the standard duel resolve-maneuver state transition pattern (Maneuver_01135 is the template)
- Private choice field `$ChooseParry` stores the decision; reset on maneuver cancel/duel end

## Implementation Complete

### Files Created
1. **Maneuver_03024.php** — the maneuver handler
   - `isAvailableToPlayer` gates on adversary being Sorcerer or Monster
   - `EventManeuverActivated` queues transition to duel-resolve-maneuver state
   - `EventDuelCalculateManeuverValues` applies +2 Parry or +2 Thrust based on `$ChooseParry` flag
   - `EventManeuverCanceled` resets the choice flag
   - `actFromManeuverWithId` handles the player's choice (id=1 for Parry, id=2 for Thrust)

2. **State_duelResolveManeuver_03024.php** — GameState class for the choice state
   - Transition name: "" (default)
   - Description and action: `actFromCardWithId`

### Files Modified
1. **States.php** — added `const DUEL_RESOLVE_MANEUVER_03024 = 52503024;`
2. **states.inc.php** — added transition mapping in DUEL_RESOLVE_MANEUVER_EVENTS

4. **OnUpdateActionButtons.faf.js** — added button handlers for "+2 Parry" and "+2 Thrust"

### Design Notes
- **No special gate beyond Sorcerer/Monster:** the card has no Gambling gate, no trait restriction on the actor, just a straightforward adversary-type check
- **Default to Thrust:** the `$ChooseParry = false` default means if the flag isn't explicitly set to true, the maneuver applies Thrust. This is arbitrary but consistent
- **eventManeuverActivated uses stackEvent:** follows the pattern from Maneuver_01135 for predictable ordering of the state transition
- **No EventResolveManeuver handler needed:** the effect is pure calc, applied entirely in EventDuelCalculateManeuverValues
