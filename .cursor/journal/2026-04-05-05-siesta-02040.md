# Siesta (_02040) — City Action Implementation

## Card Text
**City Action:** Move your performer **Home** engaged. Then, they heal a wound.

## Implementation

Simplest possible City Action on a Risk card. No target selection, no custom state — the action auto-resolves entirely in `handleEvent`.

### Pattern
Follows `Action_01103a` (direct-resolve, no `createTransitionEvent`) combined with:
- Move-home-engaged from `Action_01104` line 103
- Heal from `Action_01136` line 83

### Key Decisions

**No wound gate on `isAvailableToPlayer`/`getPerformersForAction`:** The card text says "move home engaged, **then** heal a wound." The move is useful on its own as a retreat even without wounds — gating on wounds would unnecessarily restrict the action. The heal event handles the zero-wounds case gracefully.

**No trait gate:** Card text says "City Action:" with no qualifier (not "Pirate City Action:" or "Diplomat City Action:"), so any performer in the city qualifies.

**`RiskCityAction` base handles everything:** The parent class already checks card-in-hand and performer-in-city. No need to override `isAvailableToPlayer` or `getPerformersForAction`.
