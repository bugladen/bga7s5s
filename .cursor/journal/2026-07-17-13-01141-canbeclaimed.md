# Action_01141 CanBeClaimed Availability Gate

Eddie: Action_01141 needs to check `theah->canLocationBeClaimedBy` in order to be used.

## Decision Before Edit

This is another card in today's claim-gate sweep. `Action_01141` already rechecks
`canLocationBeClaimedBy` after pressure succeeds, but it can still be offered when all
combat-pressure performers are standing at locations that cannot be claimed.

WHY fix availability/performance selection, not only resolve: the action's purpose is
pressure-then-claim. If the claim cannot happen, allowing the action wastes the Risk and
the turn flow. Filtering performers is important because this card lets Eddie choose a
performer; one blocked location should not hide the action if another combat-pressure
performer is at a claimable location.

WHY use `canLocationBeClaimedBy($playerId, $character->Location)` instead of reading
`CanBeClaimed` directly: this is now the central rule API, with `$playerId` intentionally
reserved for future per-player claim restrictions.

## End State

Implemented a private `getEligiblePerformers()` helper and routed both
`isAvailableToPlayer()` and `getPerformersForAction()` through it. The helper requires
both `canPressure(Game::STAT_COMBAT)` and `canLocationBeClaimedBy($playerId, location)`.

Kept the existing resolve-time recheck in `EventLocationPressureResult`. WHY: availability
can be computed before later reactions/events alter location claimability, so the final
claim emit still needs to be guarded.
