# Blood Like Winter (02048) Implementation

## Card Overview
Ussura Risk card with City Reaction: "When your opponent's risk targets your performer - Pressure your performer's location with [combat]. If successful, cancel the effects."

## Design Decisions

### WRONG: EventRiskPlayed trigger with CHOSEN_TARGET/CHOSEN_PERFORMER
First two attempts tried to trigger on EventRiskPlayed:
1. Checking CHOSEN_TARGET - fails because target isn't set until action's own state resolution
2. Checking CHOSEN_PERFORMER to find location - still fires too early, before effects are queued

WHY these failed: For ALL in-hand risk actions, effects are queued during `actFromActionWithId` in the action's custom state, AFTER EventRiskPlayed and EventActionTriggered have already fired. The action controls its own target selection flow.

### CORRECT: Individual effect events (Maryam pattern)
Following _01186 (Maryam Benu Pleroma), trigger on the INDIVIDUAL EFFECT EVENTS:
- EventCardEngaged (cardId = my character being engaged)
- EventCardMoved (cardId = my character being moved)
- EventCharacterBeingWounded (characterId = my character being wounded)
- EventChallengeIssued (defenderId = my character being challenged)

Each event carries `sourceId` which traces back to the risk card. Check `sourceId` is a `Risk && IRiskThatTargetsCharacters` owned by opponent. This fires at exactly the right time - when the risk's effects actually target my character.

### Clone-and-re-emit pattern (from Reaction_02016)
Unlike Maryam (who cancels unconditionally), Blood Like Winter's cancel is conditional on pressure success. So we:
1. Cancel the event (`$event->canceled = true`)
2. Clone it (`clone $event; unset($clone->theah)`) for possible re-emission
3. Offer reaction with performer choice
4. If pressure succeeds: discard clone, auto-cancel subsequent events from same sourceId
5. If pressure fails or declined: re-emit the cloned event

### Auto-cancel subsequent effects
After a successful pressure, save the `RiskSourceId` and auto-cancel all subsequent events from that source (same as how Maryam cancels each targeting event). Clean up at EventPlayerTurnEnd.

### Pressure with Combat
Followed the pressure pattern from Reaction_01080 (Pressure Location After Duel):
1. Set PRESSURE_TYPE to NORMAL
2. Get pressure stats for combat
3. Queue EventPressureOccuring
4. Call pressureLocation() synchronously
5. Queue EventLocationPressured with result
