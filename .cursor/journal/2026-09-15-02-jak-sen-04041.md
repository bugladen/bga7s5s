# Jak-Sen _04041

Finished BAS character: Sorcery combat-card Lethal passive + City Reaction cancel opponent move/engage.

## Abilities

1. **Passive** — When Jak-Sen's combat card is Sorcery, gain Lethal.
2. **City Reaction** — When your character at his location would be moved or engaged by an opponent's effect, cancel that move or engage.

## Decisions

**Lethal = Rosa `_02033` shape** — `EventDuelCalculateCombatCardStats` + `actorId == $this->Id` + `getCardObjectFromDb(combatCardId)` + `hasTrait("Sorcery")` + `createGainLethalEvent`. WHY not a Technique: printed text is an unconditional duel passive, not a chosen Technique (contrast Elena/Daichi trait-gated Techniques). Used `hasTrait("Sorcery")` not `clienttranslate('Sorcery')` — Elena/Daichi convention; Rosa's `clienttranslate('Revelry')` is the odd one out.

**Reaction cancels only the move/engage event** — not `deleteEventBatch` / Unyielding Loyalty full-ability cancel. Text says "Cancel that move or engage," so a wound queued after the move still fires.

**Two event types, two Decline guards** — Moving already has `cancelDeclinedByCardIds` (Stubborn/Ise). `EventCardEngaged` does **not** — used `skipNextEngagedEvent` like Unyielding Loyalty `Reaction_01032` rather than adding a new field to Engaged. WHY not add the field: single Reaction needs one Decline skip; skip flag is established and smaller than event-schema churn.

**Opponent's effect = Aimée `isOpponentEffect`** — `sourceId`/`abilityId` controller check; `sourceId==0` is framework auto-engage / dusk move-home, not an effect. Do **not** use `initiatingPlayerId` (Maneuver_01033 victim trap).

**Location gate on Moving uses `fromLocation`** — `EventCardMoving.runEventHubAfterCards` defers the location write; character still "at" Owner's location via fromLocation.

**City Reaction `cardInCity`** — required by keyword. Includes Jak-Sen himself ("your character at Jak-Sen's location").

**No Title** — scaffold omitted it; did not invent one. Traits kept as stub (no Ussura nation trait — `initializeFaction` covers faction).

**No states/JS** — button Reaction + card-local passive only.
