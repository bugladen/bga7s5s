# Night of Drinking clone `_01109v2`

User asked to clone `_01109` (Night of Drinking), its composites, states, and supporting code into `_01109v2`. Same printed card. Castille starter decks stay `01109`.

## What it actually has

One composite: `Reaction_01109`. No class-based state, no JS state handlers, no `States.php` constant, no zombie case. The reaction uses the shared in-hand reaction / pay flow (`createReactionTransitionEvent`, `PAY_STATE_IN_HAND_REACTION`). Nothing to register in `states.inc.php`.

## De-dupe key

Copied the two `areTransitionEventsOfTypeForPlayerQueued` checks and pointed them at `"Reaction_01109v2"`. WHY: ability `Id` is `{cardId}_` + unqualified class name. The original looks for its own class so two copies collapse to one offer. Leaving the string as `Reaction_01109` would still match a v2 id, because the DB check is `LIKE '%Reaction_01109%'` and `Reaction_01109v2` contains that substring. The clone must name itself or two v2 copies are de-duped only by accident of the original's prefix.

One-way collision left on purpose. Original `_01109` was not edited (same rule as the Kaspar/Rosine clones). A queued v2 offer therefore suppresses an original Night of Drinking in the same hand; a queued original does not suppress v2. Decks should swap `01109` for `01109v2`, not mix them. Tightening the original LIKE would be a behavior change to a card the user did not ask to touch.

Maneuver path still has no de-dupe. Copied as-is. Edge cases (Not Today, Stubborn, Unyielding Loyalty, Soline ActionResolved) stay inside the reaction, so they came along with the copy. Comments on other cards that mention 01109 are about the original mechanic and were left alone.

## Trigger narrowed to Action or Reaction

User updated the printed text to: when an Action or Reaction on a non-Sorcery risk is announced, cancel its effects. Original `_01109` is untouched.

Removed from `Reaction_01109v2` only:

- `EventManeuverActivated` offer, `ManeuverId`, and `deleteManeuverEvents`. A maneuver is not an Action or Reaction, so there is nothing left to remember.
- Not Today (`_01169`) `EventDuelCalculateCombatCardStats` offer and `cancelEscape()`. That window is the Forced combat-card reveal, not an announced Action or Reaction. Without the trigger, `cancelEscape` could never run.

Kept on purpose:

- `EventActionActivated` for Risk Actions, including the Soline `ActionResolved` fire after the ActionTriggered row is deleted.
- `EventRiskPlayed` only when a `RiskReactionTriggered` for that source is still queued. That is how Risk Reactions announce; they never fire `EventActionActivated`.
- Stubborn (`_01140`) and Unyielding Loyalty (`_01032`) `revertCancellation` on resolve. Those cards *are* Reactions. Cancelling them still has to undo the thing they already cancelled. That is resolve cleanup, not a third trigger.
- Sorcery and `effectsCannotBeCancelled()` gates. The new text still says non-Sorcery, and Celerity-style "cannot be cancelled" is still an Action/Reaction on a Risk.

Reaction `Name` is now "Cancel a Non-Sorcery Risk Action or Reaction" so the short label matches the text. De-dupe key stays `Reaction_01109v2`.

Tests: maneuver announce and Not Today combat-stat both assert zero offers. Maneuver-delete resolve test removed because that path cannot start. Suite: 18 passed.
