# Improvising (01106) + Press the Advantage (01058) — log move, no board move

## Report
Action_01106 pulled 01058 from discard. Costs paid, target chosen. Log: "has chosen to engage … and move them HOME." Character never moved. Stack also showed sink/locker/"Action has resolved" *before* the choose-target line.

## WHY
Pay discards the `_01106_RiskClone` shell. Old handler immediately queued permanentlyHide + sink original + locker Improvising + ActionResolved.

`buildCity` does not load Permanently Hidden. Next request (01058 target pick):
- `actFromCardWithId` still finds the shell via `getCardById` DB fallback → notify fires
- `nextState` → `stRunEvents` → fresh `buildCity` → shell absent from `$this->cards`
- `EventCharacterTargeted` never reaches cloned `Action_01058::handleEvent` → no engage/move

Card text: "After it resolves, sink it." Discard-from-hand is pay-time, not resolve-time.

## Fix
`_01106_RiskClone`:
- On discard: set `PendingCleanup`, do nothing else (shell stays in Owner discard → still in buildCity)
- On `EventActionResolved` for ControllerId when `CHOSEN_ACTION` starts with `{shellId}_`: hide shell, sink original, locker Improvising
- No second ActionResolved (stolen action / UL cancel already emitted one)

WHY CHOSEN_ACTION prefix: avoid cleaning up on an unrelated ActionResolved for the same player.
