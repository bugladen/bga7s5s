# Iago Carlos de Soldano _04033

Finished BAS Castille character: duel Pirate/Scoundrel trait grant + Thrust/Parry Technique with deferred optional threat.

## Abilities

1. **Passive** — While participating in a duel, gains Pirate and Scoundrel.
2. **Technique** — +1 Thrust or +1 Parry. At the start of the adversary's next round, you may add a threat to Iago.

## Decisions

**Trait grant = addTrait/removeTrait with `$DuelTraitsApplied` flag** — mirrors El Gato Mask `_03043` for grant/remove, plus Térence `_03028` participation lifecycle (`EventDuelStarted`/`End` + Challenger/Defender swapped). Flag prevents double-apply and ensures we only remove what we granted. Notified via traitAdded/traitRemoved.

**No re-`IHasTechniques` / `TechniqueTrait`** — Character already has both (checklist 80 / Andare `_04031`).

**Thrust/Parry choice = Vissenta `01013` buttons** but with `createTechniqueTransitionEvent` (HIGHEST_PRIORITY) instead of `createTransitionEvent`+HIGH_PRIORITY — WHY: Calculate is queued right after Resolve; choice must land before Calculate reads `$UseThrust` (Ekaterina `03049` pattern).

**Deferred threat = Lorenzo `01090` NewRound pattern** — arm `$PendingThreatChoice` on Resolve; on `EventDuelNewRound` when `actorId != Iago`, queue same transition key `"04033"`. Dispatcher-scoped: `DUEL_CHOOSE_TECHNIQUE_EVENTS` → choose Thrust/Parry; `DUEL_NEW_ROUND_EVENTS` → Add Threat / Pass. Clear flag before queueing so we only prompt once. Skip/clear if Iago is in discard/locker. Clear on cancel / DuelEnd.

**Threat mapping** — `createThreatModifiedEvent` with Iago Id → challenger or defender delta (Axelle `Reaction_04022` shape). Text says "to Iago", not "your participant".

**"Razor" added to TraitNames** — scaffold printed it; was missing from `$TraitsJson` (checklist 65).

**States** — `DUEL_CHOOSE_TECHNIQUE_04033` (52104033) + `DUEL_NEW_ROUND_04033` (5104033). Button-only JS in `OnUpdateActionButtons.bas.js` only (no Entering/Leaving — same as 01013). Zombies `nextState` (Parry default / decline threat).
