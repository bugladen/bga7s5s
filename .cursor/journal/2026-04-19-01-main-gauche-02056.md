# Main Gauche (_02056) Implementation

## What was done

Implemented the Main Gauche card - a Neutral FactionAttachment (OffHand Weapon/Melee/Dagger) with:

1. **Duelist equip restriction** - `canAttachTo()` checks `hasTrait("Duelist")`, `eventCheck()` validates at equip time with BgaUserException. Follows the exact pattern from Mastercrafted Rapier (_01074).

2. **Conditional Technique** - Created `Technique_02056` that gives +1 Parry by default, or +1 Riposte if the equipped character has 3+ ModifiedFinesse. Used `getOwningCharacter()` which correctly follows the attachment chain (attachment -> character) via `CardAbilityTrait.php:86-103`.

## WHY decisions

- Used `getOwningCharacter()` instead of `getDuelRoundActor()` because the card says "your participant" meaning the character this attachment is equipped to. `getOwningCharacter` on a technique owned by an attachment follows the chain: technique -> attachment -> attached character. `getDuelRoundActor()` would also work in most cases but `getOwningCharacter` is more semantically correct and safer if there are edge cases with multiple duelists.

- Checked `ModifiedFinesse` (not base `Finesse`) because Technique_01128 uses `ModifiedFinesse` for its threshold checks. ModifiedFinesse includes stat modifiers from attachments and other effects, which is the right thing to check during a duel.

- The technique's `isAvailableToPlayer()` only checks IN_DUEL (not Finesse threshold) because the technique always applies - the Finesse check just determines which bonus you get. This differs from Technique_01128 which gates availability on stats because its bonuses are independent (can get Parry, Thrust, or both).
