# Reaction_01080 CanBeClaimed Offer Gate

Eddie: Reaction_01080 needs to check `theah->canLocationBeClaimedBy` to be used.

## Context

Continuation of today's claim-gate sweep (01095a, 01130, 02029, 01075, 01126).
Resolve path already guarded claim emit with `canLocationBeClaimedBy` (EventLocationPressureResult).
Offer path on EventDuelEnd did not — so "Pressure Location After Duel" could still be offered
when Leshiye / Indomitable Will had blocked claims at `$this->DuelLocation`.

## Change

In `EventDuelEnd` handler, added claimability to the offer condition:

```php
if ($owner->Location == Game::LOCATION_HAND
    && $event->theah->canLocationBeClaimedBy($owner->ControllerId, $this->DuelLocation))
```

WHY gate at offer (not only resolve): this reaction exists to pressure-then-claim;
offering it when claim is impossible wastes the hand reaction / pay cost.
WHY `canLocationBeClaimedBy` not `$location->CanBeClaimed`: central API, `$playerId`
reserved for future per-player rules (same as 01075/01095a/01130).
Resolve-time recheck kept because claimability can change mid-flow.

Player id: `$owner->ControllerId` — same player who pressures/claims via DuelOpponentId performer.
Location: `$this->DuelLocation` (saved from dying character at destroy time).
