# Borets (_01129) Audit

## Card Text
> Maneuver: For the rest of the duel, other Maneuvers and Techniques cannot be used.

## Result: All Correct

Straightforward maneuver card. The implementation is clean and correct. Two files: `_01129.php` (card def) and `Maneuver_01129.php` (maneuver logic).

The key insight is the event ordering: `EventManeuverActivated` → `EventResolveManeuver`. The `IsActive` flag is set on `EventResolveManeuver`, so the maneuver's own activation `eventCheck` passes (IsActive is still false at that point). After that, all subsequent maneuver/technique activations are blocked by the `eventCheck` throwing `BgaUserException`.

The "other" word in the card text is handled implicitly — the base `Maneuver` class marks it as "used" after activation, so re-activation is already prevented independently of the `IsActive` blocking.

Clean audit, nothing to fix. This is a well-implemented card.
