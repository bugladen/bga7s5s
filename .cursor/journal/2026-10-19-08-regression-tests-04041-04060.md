## Test footguns (these failed the first run; the cards were right)

- Composite `handleEvent` reads `Event::$theah` in the parent. `fire()` / `fireOn()` set it; a bare `new Event` does not. Suites call `$world->fireOn($owner, $event)` so the owning card forwards to the composite. Safe here because Character and the scheme overrides call `parent::handleEvent`, which is the ability loop. Two techniques/maneuvers/reactions on one card are id-gated, so the other no-ops.
- `actFromCardWithId` / `actFromCardWithIds` are `(Game, state, stateName, internalId, id|ids)`. The tests were missing the `internalId` string, so the id array landed in the string slot. Pass it `''`.
- `_04044` claim recompute compares `leader->Location` to the claimed location. `EventCardMoved` applies the bonus from `toLocation` because Location is still the old spot (`runEventHubAfterCards`). The test must stamp `Location = forum` before the claim, which is what production looks like after the move has resolved.
