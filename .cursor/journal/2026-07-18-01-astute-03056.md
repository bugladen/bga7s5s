# Astute (_03056) — create-risk

## Card text
**City Action:** Target an opposing character • If their controller does not control this location, they claim it and you move a Renown from this location to another.

Risk / Virtue / Cunning. Ussura. Wealth 0. Dashed Riposte, Parry 2, Thrust 3.

## Context
Continuing FAF Ussura after Syrneth Compass (_03055). Pure Pattern A City Action — no Maneuver.

## Approach / WHY

### "they claim it" = opponent, not you
Printed clause distinguishes **they** vs **you** in the same sentence. "They" = target's controller (via the targeted character as claim performer). "You" = active player moves Renown.

This is the devil's-bargain reading (flavor literally draws The Devil): you gift/steal claim for the opponent in exchange for a Renown move. Alternatives considered and rejected:
- You claim: would rewrite "they" → "you"; grammar fights it
- Claim only when uncontrolled: text says "does not control", which includes you-control and third-party-control — opponent can steal your claim

### Shape
- `RiskCityAction` + `IAbilityThatTargetsCharacters` + `RequiresPerformerSelected`
- Risk marked `IRiskThatTargetsCharacters` (character chooser)
- Two GameStates: `03056` character pick → EVENTS (claim flushes) → `03056_2` location pick for Renown
- Claim: `createLocationClaimedEvent($target->ControllerId, $target->Id, $location)`
- Renown move: Moving + Removed + Added with shared `batchId` (same idiom as `Reaction_03041` / `Action_01117`)

### Availability gates (all required for a live target)
1. Opposing character at performer's location
2. That character's controller ≠ `getControllerForLocation` (the "if" clause)
3. `canLocationBeClaimedBy(targetController, location)` — Leshiye / IW etc.
4. Location Renown ≥ 1 — "and you move a Renown" is half the effect; no Renown = dead bargain / free claim with no payoff. Gate both halves together.

Stash `CHOSEN_LOCATION` at target confirm so Renown source survives claim reactions / board shifts before the chooser.

### Race / unclaimable after announce
If claim becomes illegal between availability and confirm, notify + `ActionResolved` (mirror `Action_03053` / `Action_01130`). If Renown somehow hits 0 after claim, skip `03056_2` and resolve.
