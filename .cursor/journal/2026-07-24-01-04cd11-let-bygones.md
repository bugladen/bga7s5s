# _04cd11 Let Bygones Be Bygones (bas City Event)

## Card Text
**Forced:** At the beginning of Dusk • Each player must choose one of their characters here. Those characters each heal a wound and do not move Home during Dusk.

## Classification
Forced with interactive per-player choice — NOT pure Forced like `_04cd07`. Needs Dusk begin state + multi-player transition queue (Chance Meeting / Penya dusk pattern).

## Plan / WHY
1. Trigger: `EventDuskPhaseBegin` + `cardInCity($this)` — same gate as Penya `_01177`.
2. Eligible players: anyone with ≥1 character at this location, in `turn_order` (initiative). Skip players with none — Forced only applies to "their characters here."
3. Queue one `createTransitionEvent(..., "04cd11")` per eligible player — sequential via DUSK_PHASE_BEGIN_EVENTS, same as Action_03cd03's per-player muster loop.
4. Stay-home: new condition `LET_BYGONES_BE_BYGONES` + `eventCheck` on `EventCardMoved` → Home (Penya / Under Cover of the Night). WHY new condition not reuse HELPED_BY_PENYA / UNDER_COVER: condition string shows on the character UI; wrong flavor if reused.
5. Heal: always queue `createCharacterBeingHealedEvent(..., 1, ...)` — Character clamps 0 wounds; Forced doesn't say "if wounded."
6. No Pass — Forced "must choose." Zombie auto-picks first eligible character.
7. State class (modern bas/tac dusk pattern) + card owns args/act/handleEvent/eventCheck. JS in `.bas.js` mirroring duskPhaseBegin01177 character picker (no Pass button).

## Alternatives considered
- Pure Forced auto-pick (e.g. least wounded): violates "must choose."
- Reaction shape: printed Forced, not optional Reaction.
- Cancel EventCardMoving like Stubborn: Penya audit says EventCardMoved-block is the established dusk stay-home path; keep consistency.
