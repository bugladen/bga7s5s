# _04cd04 Astrid de Martinez (bas City Character)

## Card Text
- Negotiable (property, already stubbed)
- En Garde — Astrid gains +1[Influence] during pressures initiated by an opponent
- Action: Engage Astrid • An adjacent location becomes uncontrolled. Move Astrid there.

## Classification
1. Negotiable → `$this->Negotiable = true` (done)
2. Pressure-only Influence bonus → Claude `_01184` `getInfluencePressureValue`, gated on `PRESSURING_PLAYER != ControllerId`
3. In-play Action (not City Action) → Pattern C CharacterAction + location picker state

## WHY choices
- Mirror Claude for pressure Influence, NOT Angeline/Pavel ModifiedInfluence. WHY: "during pressures" is pressure-count only; permanently bumping ModifiedInfluence would show on the card outside pressures and wouldn't auto-clear when the pressure ends.
- Gate on `Game::PRESSURING_PLAYER != $this->ControllerId` (and require PRESSURING_PLAYER set). WHY: Claude's unconditional +1 is wrong for Astrid's "initiated by an opponent" clause; PRESSURING_PLAYER is set on every pressure path before `pressureLocation` runs.
- Action is NOT City Action — gate on `isControlled()` + `!Engaged` + eligible adjacent controlled locations, not `cardInCity` as "still in deck." WHY: printed Action applies once mustered; Penya's `cardInCity` gate is for City Actions that fire while unmustered.
- Eligible locations = adjacent city locations that currently have a Controller AND `canLocationBecomeUncontrolledBy`. WHY: "becomes uncontrolled" implies currently controlled; already-uncontrolled or CanBecomeUncontrolled=false (Leshiye-style) are no-ops / illegal.
- Engage as cost via `createCardEngagedEvent`, move with `engage=false` (Pattern C / Penya / 04cd01). Order: engage → uncontrolled → move.
- State id `4040004` / transition key `04cd04` following bas 04cd01 conventions.
