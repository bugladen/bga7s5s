# Action_01095a / 01130 CanBeClaimed via helper

Eddie: Patricia's "Claim The Docks" must check location CanBeClaimed. Then asked whether 01095a and 01130 should use explicit `$location->CanBeClaimed` or `canLocationBeClaimedBy`.

## Decision

Prefer `Theah::canLocationBeClaimedBy()` for all claim *gates*. WHY: it's the central API; comment reserves `$playerId` for future per-player rules. Direct property reads skip that. Writers still sync `$location->CanBeClaimed` + globals (`setLocationClaimFlags`).

## Changes

1. `Action_01095a` — reverted from explicit property back to `canLocationBeClaimedBy` in availability + handleEvent.
2. `Action_01130` — `isViablePerformer` and resolve-time guard now call `canLocationBeClaimedBy`; still uses `$location` for `isControlled()`. Writers unchanged.
