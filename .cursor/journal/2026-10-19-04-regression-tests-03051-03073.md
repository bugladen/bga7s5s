## Harness (do not "simplify" these)

- `FakeGame::CENSURE_CHALLENGE_TYPE = 24` and `COURAGEOUS_CHALLENGE_TYPE = 33`. Must match `Game.php`. Action_03057 / Action_03058 set these. A missing constant is a fatal, not a failed assertion.
- `TestTheah::getStartingDuelThreat` is overridden. WHY: the real method SELECTs `duel_round`. The DB stub's `getObjectList` returns player scores, so Comforting (`Maneuver_03070`) would always see excess 0. Unlisted ids are 0. Set `$theah->startingDuelThreats[$id]`.
- `TestWorld::fireOn` typehints `Card`. Actions, reactions, techniques, and maneuvers must set `$event->theah` and call `handleEvent` themselves. Cards (schemes, attachments, risks) still use `fireOn`.
- `TestTheah::eventCheck` does not walk cards. Call `$maneuver->eventCheck` directly. That is why Harpoon's throw on `Maneuver_03069a` is tested that way.
- `php tests/run.php` on Windows only treats a path as absolute if it contains `\` or a drive prefix. Relative `tests/regression/...` becomes `tests/tests/...`. Pass `c:\code\7s5s\tests\regression\...`.

## Two controller stores

`Game::setControllerForLocation` writes `Control_{location}` and is what Action_03056 and Action_03071 read. `$theah->setLocationController` writes `CityLocation->Controller` and is what Action_03067 `countControlledLocations` reads. Setting only one of them will make the other card look uncontrolled. Do not collapse them.
