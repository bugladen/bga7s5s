# Action_01075 CanBeClaimed Availability Gate

Eddie: Action_01075 needs to check `theah->canLocationBeClaimedBy` to be used.

## Context

Continuation of today's claim-gate sweep (01095a, 01130, 02029, 01126). Resolve path
already guarded claim emit with `canLocationBeClaimedBy` (lines 79–90). Availability
did not — so the tabard pressure action could still be offered when Leshiye / Indomitable
Will had blocked claims at that location.

## Change

Added availability check in `isAvailableToPlayer` after city/engage/pressure-stat gates:

```php
if ( ! $theah->canLocationBeClaimedBy($playerId, $owner->Location))
{
    return false;
}
```

WHY gate at availability (not only resolve): pressure here exists to claim; offering it
when claim is impossible wastes engage + turn. WHY `canLocationBeClaimedBy` not
`$location->CanBeClaimed`: same as 01095a/01130 — central API, `$playerId` reserved for
future per-player rules. Resolve-time recheck kept because claimability can change mid-flow.
