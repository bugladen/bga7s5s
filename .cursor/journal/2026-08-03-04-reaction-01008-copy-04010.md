# Reaction_01008 — Copy Action_04010 (Unravel the Thread)

## Context

Eddie asked to ensure Cesca (`Reaction_01008`) can copy `Action_04010`. Fresh from implementing Unravel the Thread (`2026-08-03-03`). Checklist rule: any new `ISorcererAbility` that Cesca can be the performer of (or that targets a character at her location) needs an `isCopyable` + `performReaction` entry.

## Reachability

`Action_04010` does **not** implement `IAbilityThatTargetsCharacters` and fires `SorcererAbilityPlayed` with performer only (no target). So Cesca's trigger only opens when she is the performer (`$event->performerId == $cesca->Id`) — i.e. she played Unravel herself. Still copyable per printed text ("After Cesca performed a Sorcerer Ability…").

## Approach

Same Risk-card pattern as Fate's Kiss / Follow the Thread / etc.:
1. `use Action_04010`
2. `isCopyable` allow-list entry
3. `performReaction` → `$cardCopied = true` + `copyCard("04010")` → pay-from-hand flow

WHY card copy (not host action on Cesca): it's a `RiskAction` with wealth cost 2 and "sink this card" — needs a real hand card so pay + discard + sink-self resolveFinish path works unchanged. Hosting a bare Action on Cesca would skip wealth pay and break the sink-self assumption that the Risk is already in discard.

## Not done

`Reaction_04010` (gamble-reveal Sorcerer Reaction on the same card) — Eddie only asked for Action_04010. Gambling-reveal copy would need a different shape (deck peek, not hand Risk).
