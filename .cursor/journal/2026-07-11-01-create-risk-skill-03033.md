# create-risk skill update — Glorious (_03033) learnings

## Why

Eddie asked to capture session learnings from implementing Glorious into `create-risk`. Prior skill already had Pattern A.2 (_03032) and D.4 (_03031); Forced-on-Risk and equal-or-greater Influence comparison were gaps that would cause future agents to invent Forced ability files or copy `_03008`'s strict `>` onto "equal or greater" cards.

## What was added

1. **Canonical ref** `_03033` Glorious
2. **Ability-shape table** — Forced → Pattern E.1 row
3. **Influence comparison** — wording table (`>` vs `>=` / `<=`) + discard/locker gate for wound-adversary availability
4. **Pure-resolve Maneuver** subsection (mirror of pure-calc) with wound template
5. **Pattern E.1** — Forced on Risk class: gate chain, challenger/defender survivor lookup (not round actor), heal discipline, WHY no Forced ability file
6. **Reference table** row + combining-examples sentence
7. **When You Finish** items 23–24; item 1 now lists Forced; item 7 expanded for comparison wording

## Feelings

E.1 is the important one — Forced is easy to over-engineer. The `>=` vs `>` note is small but the kind of silent bug that ships when someone mirrors Arrogant without reading the new card's words.
