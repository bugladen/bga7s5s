# Severing Arc (_04050) Implementation

## Card Text
1. After the adversary performs a **Technique**, if this card is in your dueling line, they suffer a wound. (no Forced: keyword, but no player choice)
2. **Duelist Maneuver:** +1[Thrust]. Engage the adversary and each of their equipped attachments.

## Classification
- Clause 1 → Pattern E.1 on Risk class (`handleEvent`) — mirror Glorious `_03033` shape, different trigger
- Clause 2 → Pattern C Duelist Maneuver: calc +1 Thrust + resolve engages
- No Cesca / no states / no JS

## WHY EventResolveTechnique (not Activated / Used)
"After … performs" = technique successfully completed. Cancel reactions (Reaction_01047) fire on `EventTechniqueActivated` and delete technique events before Resolve — so cancelled Techniques must not wound. `EventTechniqueUsed` is only the setUsed notify path, not "performed."

## WHY skip already-Engaged on Maneuver engage
`EventCardEngaged` hub always notifies even if already Engaged. Skip `!Engaged` for adversary + real attachments (same discipline as Maneuver_01086 / Action_03072 engage half). Skip FakeAttachment. Do **not** grey Maneuver when everything is already Engaged — +1 Thrust is still useful.

## WHY Duelist-only availability gate
Same as `_04046` / `_04048`: trait gate only; resolve engages are best-effort.
