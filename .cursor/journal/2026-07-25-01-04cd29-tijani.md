- **Finesse "If" into eligibility:** filter targets to `ModifiedFinesse < Tijani.ModifiedFinesse` for availability + picker. WHY: once-per-day action; offering a no-wound target would burn Used. Mirrors Technique_03002/03043 gating the If into isAvailable. Resolve still re-checks Finesse before wounding.
- **Gambling Technique:** DUEL_GAMBLED + actor == Tijani + adversary Finesse < Tijani; wound on `EventDuelCalculateTechniqueValues` via `createCharacterBeingWoundedEvent` (Technique_03004/03014 shape).
- **Jaragua** missing from TraitNames — add alphabetically.
