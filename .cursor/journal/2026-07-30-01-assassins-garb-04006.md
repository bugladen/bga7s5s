# Assassin's Garb (_04006)

## Orientation

BAS Vodacce FactionAttachment (Attire / Mantel / Stealth). Scaffold has stats + Text; abilities unimplemented. Mantel missing from TraitNames.

## Classification

1. **Pattern A:** May only equip to your Duelist, Spy, or Assassin — dual-gate `eventCheck` + `canAttachTo`.
2. **Duel passive (not Forced/Action/Reaction):** During a duel, while adversary wounded → equipped character +1 Finesse **and** +1 gamble reveal.

## Design decisions (WHY)

- **Finesse:** Benci `_04001` flag + `createCharacterFinesseModifedEvent` delta — NOT constructor `FinesseModifier` (that is always-on). "During a duel" + "while adversary wounded" is dynamic; flag prevents double-apply across wound/heal/swap/DuelEnd.
- **Gamble +1:** Gallegos `_01101` / Devil Jonah `_03cd05` `getNumberOfGambleCardsToReveal` — check same wounded-adversary gate at gamble time (no flag needed). Base gamble count is 2 + modifiers; Finesse separately caps how many gambles (`actDuelActionGamble` / gamblesLeft), so both halves of the printed text matter.
- **Adversary wounds stale:** Mirror Benci `characterHandled` delta on Wounded/Healed — hub order isn't guaranteed.
- **Unequip:** EventHub clears `AttachedToId` before card handleEvent (no `runEventHubAfterCards`) → use `$event->characterId` to undo bonus.
- **UserException:** framework path per skill (not legacy `BgaUserException` on `_01073`).
- **No condition stamp / JS:** Benci doesn't stamp a Game condition for the combat bonus; Finesse modified event updates the stat UI. Skip Soline-style condition unless Eddie wants tooltip.

## Alternatives considered

- Always-on FinesseModifier: wrong — not "during a duel / while wounded".
- Hook only EventGenerateChallengeThreat: misses mid-duel Finesse (gamble cap, comparisons); also challenge is pre-duel ("During a duel").
- Technique/Reaction class: text has no keyword ability — all on the attachment card.
