# Mōri Daichi (_03050) — create-character

## Card text
1. Daichi cannot refuse challenges issued by characters with greater [Combat].
2. When Daichi issues a challenge, characters with greater [Combat] cannot refuse.
3. Technique: If Daichi's combat card is a Flourish or Sorcery • +1 Riposte.

## Context
Continuing FAF after Ekaterina `_03049`. Scaffold was bare Character with `Usurra` typo.

## Approach / WHY

### Refuse passives — character identity, NOT a new CHALLENGE_TYPE
Aja / Épée Sanglante / etc. hang refuse locks on `CHALLENGE_TYPE` because those actions own the challenge they issue. Daichi's passives apply to **any** challenge involving him — including NORMAL challenges issued *to* him. A dedicated type would miss half the text.

Unified rule (`_03050::challengeRefusalBlocked`): if either participant is Daichi and the other has strictly greater `ModifiedCombat`, refuse is blocked.
- Challenger = Daichi + defender.Combat > daichi → rule 2
- Defender = Daichi + challenger.Combat > daichi → rule 1
- Equal Combat → refuse OK ("greater" is strict)

Wiring (server + UX + zombie):
- `actHighDramaChallengeActionReject` throws before When-Least-Expected discard route
- args flag `cannotRefuseDueToDaichi` → JS disables Refuse
- Zombie defaults to Accept when flag set (otherwise Reject would throw)

### Technique — Elena `_03004` shape
`Technique_03050`: IN_DUEL + actor-is-owner + own combat card hasTrait Flourish **or** Sorcery. `EventDuelCalculateTechniqueValues` += riposte. Filter combat cards by `ControllerId` like Elena.
