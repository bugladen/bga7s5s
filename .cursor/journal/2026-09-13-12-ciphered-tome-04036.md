# Ciphered Tome _04036 implementation

## Classification
- Pattern A: "May only equip to your Academic" — dual-gate like Pompon `_04026`
- Pattern C × 2 City Actions, both "Engage this card" + location picker
  - a: Move a Renown from this location to another City location
  - b: Move your performer to another location with more Renown

## Why these mirrors
- Equip: `_04026` (UserException, not BgaUserException)
- Location Action: `_03055` / `Action_04cd01` — sourceId = attachment, engage on resolve not trigger, move engage=false
- Dual actions: `_03038` a/b + `_04cd01`/`04cd01b` naming
- Renown relocate: `_04034` / `Action_01007` — Moving + Removed + Added with shared batchId

## Home on action b
Text says "another location" not "City location". Pattern C says include Home when the filter can match. Home has no Renown track (treated as 0), so it never has *more* Renown than a city slot. City Action also requires the performer start in the city. Omitted Home — JS stays city-only like `04cd01`, not the Home-capable `03055` handler.

## Why two GameStates
Different destination filters and different resolve (renown move vs character move). Shared picker UI would hide that.
