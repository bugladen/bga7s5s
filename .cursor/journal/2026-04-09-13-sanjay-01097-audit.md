# Sanjay (01097) Audit

Card text: "**City Action:** Target an opposing character • If their controller has fewer cards in hand than you, engage them. **Reaction:** After an opponent discards a card due to your effect • Draw a card."

## Action: City Action — Target opposing character, engage if fewer cards

No bugs found. Verified:

- **City gating**: `isAvailableToPlayer` checks `cardInCity($owner)`. Correct for "City Action".
- **Opposing characters at location**: `getTargetsForAction` uses `getOpposingCharactersAtLocation($owner->Location, $playerId)`. Returns characters not controlled by the active player at Sanjay's location.
- **Hand count condition**: `$handCount < $ownerHandCount` — strictly less than. Card says "fewer cards in hand than you". Correct.
- **Engaged filter**: `getTargetsForAction` skips already-engaged characters. Correct — engaging an already-engaged character is meaningless.
- **Pre-filtering vs. conditional engage**: The code pre-filters targets to only those meeting the hand-count condition rather than allowing any target and conditionally engaging. These are functionally equivalent (you'd never want to target someone you can't engage), and pre-filtering is better UX.
- **Server validation** (`isValidTargetForAbility`): Checks location, opposing controller, and hand count. Does NOT check engaged status, but this is harmless — UI prevents selecting engaged targets, and engaging an already-engaged character is a no-op.
- **Engage event**: `createCardEngagedEvent($owner->ControllerId, $target->Id, $owner->Id, $this->Id)` — correct params: player initiates, target gets engaged, Sanjay is source.
- **State transitions**: `handleEvent` queues transition to `HIGH_DRAMA_PLAYER_TURN_01097`; `actFromActionWithId` transitions to `characterChosen` → `HIGH_DRAMA_PLAYER_TURN_EVENTS`. All wired correctly.

## Reaction: Draw after opponent discards due to your effect

No bugs found. Verified:

- **Trigger event**: `EventCardDiscardedFromHand` — correct event type for hand discards.
- **`asEffect` check**: Card says "due to your effect". Code checks `$event->asEffect`. Framework-caused or payment discards don't trigger. Correct.
- **Opponent check**: `$event->ownerId != $owner->ControllerId` — the discarder (card owner) is not Sanjay's controller. Correct.
- **"Your effect" check**: `$source?->ControllerId == $owner->ControllerId` — the card that caused the discard is controlled by Sanjay's controller. If `sourceId=0` (framework action), `$source` is null and check fails. Correct.
- **Draw**: `createCardDrawnEvent($owner->ControllerId, ...)`. Draws for Sanjay's controller. Correct.
- **Pass handling**: Player can pass without using the reaction. `setUsed` only called on `drawCard`. Reaction remains available for future triggers if passed. Correct behavior.
- **Notification**: Announces the draw with inject code for Sanjay. Correct.

## Summary

Clean implementation. No fixes needed.
