# Proper Study (_03041) — create-scheme implementation

## Card text
1. Resolve: Add Renown to City Docks + Grand Bazaar (trivial, no choice)
2. Forced: End of Planning → Draw 2 (or 3 if control Academic), then discard equal number
3. City Reaction: After you claim a location → Move a Renown from that location to a different location

## Approach / WHY

### Resolve
Mirror `_02004` / `_03029` — fixed dual Renown, no planning sub-state.

### Forced
Mirror `_01098` Cat's Embargo pattern:
- Listen `EventPhasePlanningEnd` + `$this->Location == LOCATION_PLAYER_HOME` (chosen schemes sit at Home until Dusk locker)
- Queue N draw events, then transition `"03041"` under `PLANNING_PHASE_END_EVENTS` (NOT resolve-schemes map)
- State ID `PLANNING_PHASE_END_03041 = 2803041`
- Persist `$cardsToDiscard` on scheme so discard state knows exact count (Academic checked at Forced fire time)
- Discard via `actFromCardWithIds` + multi factionHand selection (01102 / 03038a shape)
- Clamp draws to deck+discard availability; if 0 drawable, notify and skip discard state
- Clamp required discard to hand size in args/act as safety

### City Reaction
Button destinations (Reaction_01118 shape) — source is captured claimed location; buttons = other city locs.
Gate: `EventLocationClaimed` for scheme controller AND claimed location has Renown > 0.
Use batch remove+add+moving events like Reaction_03027a / 01118.
Pass does not setUsed.
Surface claimed location name in `getReactionDescription`.
