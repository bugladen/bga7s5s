# Giacinto (01205) Audit

## Card Text
> Negotiable (You may parley when paying for this card.)
> **City Action:** Engage Giacinto • Engage target opposing character. Move them and Giacinto to the same adjacent City location.

## Bug Found: Missing victim engage event

The code engaged Giacinto (cost) and moved both characters (effect) but never engaged the target opposing character, despite the card text explicitly saying "Engage target opposing character" as the first part of the effect.

### Fix
Added `createCardEngagedEvent` for the victim, using `$giacinto->Id` as the source (consistent with how other cards attribute engage effects to the ability owner). Placed it after Giacinto's engage event and before the move events, matching the natural card text ordering:
1. Engage Giacinto (cost)
2. Engage victim (effect)
3. Move Giacinto (effect)
4. Move victim (effect)

Both engage events use `eventCheck` before `queueEvent` — same pattern as the existing Giacinto engage.
