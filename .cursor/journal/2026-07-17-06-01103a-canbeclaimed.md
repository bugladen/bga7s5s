# Action_01103 CanBeClaimed Check

Eddie: Action_01103 needs to check location `CanBeClaimed` to be usable.

## Finding

There is no `Action_01103` — Adaptable's claim ability is `Action_01103a`. It already gates both availability and resolve on `Theah::canLocationBeClaimedBy()`, which is literally:

```php
return $this->getCityLocation($location)->CanBeClaimed;
```

So `getEligiblePerformers` won't offer pirates at a blocked location, and `handleEvent` won't queue the claim if the flag flipped mid-flow.

No code change made. If Eddie meant a different action (or meant `_01126` still writing globals-only without syncing the in-memory property), need clarification.
