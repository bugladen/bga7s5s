# Kaj Kousei _04042 (BAS Relic Raider)

Finished BAS faction Character: muster → search/equip Artifact Reaction + En Garde move-opposing Action.

## Abilities

1. **Reaction** — After Kaj musters: search City Deck for Artifact, equip to your character at Home paying costs, shuffle City Deck.
2. **En Garde Action** — If you control an Artifact at this location: move target opposing engaged character to a City location you do not control.

## Decisions

**Muster OR Approach** — Checklist 24 / Joern. `EventCharacterMustered` alone misses Approach path.

**In-reaction multi-stage (not HD states / not PAY_STATE_EQUIP_ATTACHMENT)** — Muster fires during Approach and High Drama. Monet/Tomas shape: search → Home host buttons → click-to-pay. WHY not Action_01180 pay state: that state is HD-cycle coupled; Approach would not return correctly.

**Search UI = Reaction_03cd18 buttons** — Name-deduped Artifact buttons from City Deck. Trigger when ≥1 Artifact has ≥1 attachable Home host. **No affordability filter** (Yevgeni pay-time discount); Pass always. Hosts via `getCharactersAtHomeByPlayerId` — never `getCharactersAtLocation(HOME)`.

**REVERSED (2026-09-23): do NOT wealth-gate the trigger** — Earlier playtest kept the gate (empty-hand Approach skip). User corrected: fire even with empty hand because 0-cost Artifacts exist; Pass covers unaffordable cases; shuffle still required after search. See `2026-09-23-02-kaj-reaction-empty-hand.md`.

**Artifact search log (public)** — On trigger, `notify->all` with implode of `getInjectCode()` plus `"cards" => getPropertyArray[]`. WHY cards[]: City Deck Artifacts aren't in opponents' `cardProperties`; `format_string_recursive_with_injection` seeds `logCardCache` from id+type args (incl. arrays) — gamble reveal / Risk-play pattern. Without cards[], other players only get bold names / broken hover.

**Shuffle on search exit** — Parenthetical applies once the deck was searched (`$didSearch` set when reaction opens). Pass/abort after search still shuffles; Pass before looking does not apply (we open directly into search stage so Pass always shuffles — acceptable; they saw the Artifact list).

**Equip finalize** — `getRequiredAttachTargetId` + `createAttachmentEquippedEvent` (pre-commit). Payment discards queued atomically at finalize.

**En Garde = precondition only** — `!$owner->Engaged`; no `createCardEngagedEvent` (trichotomy c). Not a City Action keyword, but opposing-at-location is broken on shared Home — short-circuit Home / require city for targets (Benci shape).

**Control Artifact** — Your non-Fake Artifact on your characters at Owner's location, OR available City Artifact you already control there. Uncontrolled available Artifacts do not count.

**Destinations** — `getControllerForLocation != playerId` (uncontrolled + opponent). Exclude target's current location (move no-op). Two-step: Makepeace target picker + Depose location step (`actFromCardWithLocations`). State ids `404042` / `4040422`. Only `"04042"` in EVENTS transitions — step 2 via `nextState("characterChosen")`.

**Not City Kaj `_01180`** — Different card (faction Relic Raider vs city Thorn). No Artifact equip discount on this reprint unless printed.
