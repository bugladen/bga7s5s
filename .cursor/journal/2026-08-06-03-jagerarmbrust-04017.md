## Pattern choices / WHY
- Gamble +1 is passive while equipped + actor is host — constructor CombatModifier unused; override on card class only.
- Technique is normal Technique (keyword is Technique, not Gambling Technique). Availability: IN_DUEL + !attachment.Engaged + actor == owning character.
- Academic/Hunter is an **effect gate on Resolve**, not availability — anyone equipped can use +1 Thrust/engage; discard only if host has Academic OR Hunter. WHY: printed "If …" is conditional consequent, not cost.
- Adversary discard = Maya `Technique_01093` / Íñigo `Technique_03039` hand picker. Attachment-hosted → transition `sourceId` = `getOwningCard()` (attachment), not character. Use `createTechniqueTransitionEvent` (HIGHEST_PRIORITY) so discard picker interrupts before CalculateValues like other technique pickers (`04013`).
- Empty hand: log + skip transition (checklist 9 / 01093 shape).
- Traits printed: Primitive, Cannon — both missing from TraitNames; add alphabetically. Not adding Weapon/Ranged — scaffold only lists Primitive/Cannon.
- No Reaction/Action/Forced. No GameState when non-Academic/Hunter (immediate engage + thrust only).
