# Iaijutsu Strike (_04048) Implementation

## Card Text
Two **Duelist Maneuver**s:
1. +1[Riposte]. If this location is uncontrolled, claim it.
2. +1[Riposte]. If this location is controlled, it becomes uncontrolled.

## Classification
- Dual Pattern C Duelist Maneuvers → `Maneuver_04048a` / `Maneuver_04048b` (same discipline as `_04007`)
- Pure calc Riposte + resolve-time location claim/unclaim
- No Cesca (no printed Target / no character chooser)
- No new states / JS — resolve queues events directly

## WHY both always available (Duelist-only gate)
Both always grant +1 Riposte; the location clause is a printed **If**. Greying a when controlled (or b when uncontrolled) would hide a still-useful Riposte pick. Claimability / CanBecomeUncontrolled checked at **emit** only — same discipline as Censure refuse-claim and Indomitable Will (Reaction_04043 WHYs).

## WHY actor Location for "this location"
Mirror Maneuver_01110: adversary Location can be Locker-* after destruction mid-round; actor stays at the duel city site. Home: `canLocationBeClaimedBy` / `canLocationBecomeUncontrolledBy` already false via `locationInCity` — If clause skips or notifies.

## WHY explicit controller == 0 / != 0 before can*
`canLocationBeClaimedBy` does not require uncontrolled; `canLocationBecomeUncontrolledBy` does not require controlled. Without the controller check, the wrong maneuver's If would try to claim an already-controlled location (or unclaim an uncontrolled one). Silent return when If is false; notify only when If is true but Indomitable Will (etc.) blocks.
