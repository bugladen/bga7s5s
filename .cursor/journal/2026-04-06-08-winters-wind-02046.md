# Winter's Wind (_02046) — Scheme with Renown Placement + HD Auto-Engage

## Card Text
- **Scheme Resolution:** "Add a Renown to any location. Then, you may add a Renown to a different location."
- **Ongoing (HD):** "After any character enters play during High Drama, engage them. (Characters enter play when they are recruited, played from hand, or mustered.)"

## Implementation

### Scheme Resolution — Two-Step Optional Renown

Followed `_02005` (Decipher the Strands) pattern for the two-step location selection:
- State 1: Pick any city location → add 1 Renown, store `CHOSEN_LOCATION` global, transition to state 2
- State 2: Pick a different location → add 1 Renown → done, OR pass → done (skip second Renown)

**WHY this is simpler than _02045:** No card placement in the city, no `ChosenLocation` property on the card, no `EventSchemeMovedToCity`. The scheme just adds renown and stays at player home. Used `Game::CHOSEN_LOCATION` global to track the first location and exclude it in step 2.

**WHY separate `actFromCardPass` for state 2:** The card says "you may" for the second Renown. Unlike `_02005_2` which throws if pass is invalid (locations with no renown exist), here pass is always allowed — the player can freely decline the second Renown.

### High Drama Engage — Automatic, No Player Choice

The HD effect engages ALL characters entering play during High Drama (including the scheme owner's characters — symmetric effect, acts as a Demoralize).

**Events listened to:**
- `EventCharacterRecruited` — always fires during HD (recruiting IS a HD action), so no phase check needed
- `EventCharacterMustered` — can fire during any phase (card effects, brute play, Bravos from discard, etc.), so phase check required

**WHY NOT `EventCardMustered`:** `EventCardMustered` is a different use-case — it handles generic non-character cards entering play (e.g., `Action_01163` clone cards). All actual character entry paths (brutes from hand, Bravos from discard, card effect musters) use `EventCharacterMustered`.

**WHY no `EventApproachCharacterPlayed`:** Approach happens during Planning Phase, never during HD. The card text says "during High Drama" so approach characters don't trigger this.

**WHY automatic in `handleEvent` instead of `IHasReactions`:** The card says "engage them" with no "you may" — it's mandatory and requires no player choice. No need for a reaction transition or UI state.

### Phase Detection — State ID Prefix Check

**WHY this approach:** No `isHighDrama()` method exists in the codebase. The game state machine uses numeric state IDs where the first 2 digits correspond to the phase:
- 10-29: Dawn/Planning Phase
- 30-69: High Drama (Beginning=30, Phase=31, PlayerTurn=40, Actions=41-48, Duels=50-58, NextPlayer=59, End=60)
- 70+: Plunder/Dusk

Extracts first 2 digits of `state_id()` as string, checks `prefix >= 30 && prefix < 70`. This correctly identifies all HD states including duels, next-player transitions, and HD end events.
