## Pattern choices / WHY
- **Pressure fail:** Mirror Objection `Reaction_01027` (`EventLocationPressured` success + difference ≤1 → deletePressureResultEvents → queue failed Result). Adapt to AttachmentReaction: engage cost instead of wealth pay; no `ICancelReaction` / `EventRiskReactionTriggered` (those are Risk hand-pay plumbing).
- **"at this location":** gate `$event->location == owningCharacter->Location`.
- **Opponent-only interrupt:** Objection gates `$event->playerId != ControllerId`. Printed Pompon text doesn't say opponent, but failing your own successful pressure is nonsense for a Diplomat pet. Mirrored Objection. Flip: remove the `== ControllerId` early-out if Rules want self/ally interrupt.
- **HIGH_PRIORITY** on reaction transition — same as 01027 so offer beats LocationPressureResult.
- **Stored context:** flat fields on the reaction (not clone of whole Event) so serialization is boring/stable; clear after Fail.
- **Technique:** Copy `Technique_04017` availability (IN_DUEL + !Engaged + actor==owner) and Resolve engage; Calculate adds Parry instead of Thrust. No GameState. `EventTechniqueCanceled handler not needed` comment for pre-commit.
- **Traits:** Animal existed; Dog + Pet missing → added to TraitNames alphabetically.
