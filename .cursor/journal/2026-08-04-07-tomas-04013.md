## Pattern choices
- **Reaction:** Pattern D cancel-and-reissue (Ise `Reaction_03016a`) + Don Constanzo click-to-pay (`Reaction_03003`) + Mysta character-at-location picker (`Reaction_02037`).
  - WHY both discard events: city attachments → `EventCardAddedToCityDiscardPile`; faction → `EventCardDiscardedFromPlay`. Both `runEventHubAfterCards=true` so `$event->canceled` works (Mysta `_02037`).
  - WHY unequip stash map (`salvageableHosts`): Unequip clears `AttachedToId` before discard handlers (`runEventHubAfterCards=false` on unequip). Discard `sourceId` is NOT always the host (destroy techniques pass ability owner). Map survives multi-attachment death unequip/discard chains.
  - WHY click-to-pay in Reaction, not `PAY_STATE_EQUIP_ATTACHMENT`: discard fires mid-duel / type-limit / death; PAY_STATE returns to High Drama player turn.
  - WHY `cancelDeclinedByCardIds` on discard event classes: same Decline dance as EventCardMoving; without it re-queued discard re-triggers immediately.
  - WHY affordability gate before prompt: avoid Decline-only dead prompt (checklist valid-target precondition).
  - `getRequiredAttachTargetId` + `createAttachmentEquippedEvent` (factory creates Equipping) — pre-commit attach target requirement.
- **Technique:** Pattern E picker (02011/02026b) + PlusTwoThrust Calculate/Threat.
  - Destroy recipe: unequip + discard (`asEffect=true`); CityAttachment → city discard.
  - Skip FakeAttachment.
  - State ID `52104013` / transition `"04013"` / JS button list like 02011.
