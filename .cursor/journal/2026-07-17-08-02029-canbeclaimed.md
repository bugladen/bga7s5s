# Action_02029 CanBeClaimed Check

Eddie asked for `Action_02029` to call `Theah::canLocationBeClaimedBy()` as a
condition of use.

## Finding

The action already has the intended gate. `isAvailableToPlayer()` depends on
`getEligiblePerformers()`, and that helper only includes Diplomats whose location
passes `canLocationBeClaimedBy($playerId, $diplomat->Location)`. Resolution also
rechecks the helper before creating `EventLocationClaimed`.

WHY no code was changed: adding another check directly to `isAvailableToPlayer()`
would duplicate the performer-level rule and could drift from the list shown during
performer selection. Keeping eligibility centralized in `getEligiblePerformers()`
ensures the action button and performer choices use the same criteria. The
resolution-time check remains valuable because claimability can change after
selection.
