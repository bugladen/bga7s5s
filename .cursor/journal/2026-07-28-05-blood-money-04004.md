# Blood Money _04004 (Scheme)

## Text classification

1. **Resolve:** Add Renown to City Docks + Grand Bazaar (fixed) → Pattern A trivial.
2. **Resolve Then:** Move your Duelist to a City location → Pattern A with two planning sub-states (pick Duelist → pick City dest). Skip transition if no Duelist in play.
3. **Duelist City Action:** Move performer to a location with a wounded enemy → SchemeCityAction + Duelist trait gate + HD location pick. Dest = other City loc with ≥1 opposing Wounds>0.
4. **Duelist Reaction:** When an opposing character is destroyed • Draw a card → CardReaction on EventCharacterDestroyed. Trait gate = control a Duelist in play (Manipulative / Reaction_03010 shape — no performer in trigger).

## WHY decisions

**Initiative 8 not 64:** Card art sun icon is 8; scaffold 64 was TAC copy-paste (_02024). Fix to printed value.

**Assassination trait:** Missing from TraitNames — added after Assassin.

**Resolve skip if no Duelist:** "Then, move your Duelist" is contingent; no Pass UX if we only transition when ≥1 Duelist exists. Must-move when they do (no Pass). Dest excludes current location.

**engage=false** on both moves — text says Move only.

**City Action availability:** parent SchemeCityAction already city-performs; filter Duelist + exists destination with wounded enemy. Don't offer dead action.

**Reaction Duelist gate:** No named performer in trigger — search `getCharactersInPlayByPlayerId` for any Duelist (same as Strega Reaction_03010). Opposing = ControllerId != owner. Draw is optional (Pass without setUsed).

**Same transition key `"04004"`** on Planning resolve map and HD turn map — same as `_03030`. Distinct maps, no collision.

**CHOSEN_CARD** for Duelist id between planning states 1→2 (not CHOSEN_PERFORMER — that global is HD-action owned).
