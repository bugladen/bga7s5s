# No Steel, No Surrender (_03054) Implementation

## Card shape
- Scheme (Ussura), Initiative 5, Panache 0, Traits Kulachniy Boi + Brawl (both in TraitNames)
- Resolve: Add Renown to City Docks and City Forum (Eddie corrected — not Grand Bazaar)
- City Action: Wound unequipped performer • Pressure with Resolve. If successful, wound target opposing character and move them Home.

## Decisions / WHY

1. **Trivial dual Renown resolve** — fixed destinations, mirror `_03029` / `_03042`. No planning sub-state.

2. **Unequipped = `count($performer->Attachments) == 0`** — same gate as `Action_01131`.

3. **Performer legality** — unequipped + `canPressure(STAT_RESOLVE)` + ≥1 opposing character at location. Availability = `count(getPerformersForAction) > 0`. Payoff requires a target; no dead wound spends.

4. **Wound-then-pressure location hazard** — BeingWounded queues CharacterWounded at MEDIUM priority; Transition is priority 8, so the wound can apply (and destroy→locker) before `stHighDramaPressureLocation`. That state reads `$performer->Location` when `CHOSEN_PERFORMER != 0`. **Fix:** stash city location in `CHOSEN_LOCATION`, stash performer id in `CHOSEN_CARD`, set `CHOSEN_PERFORMER = 0` so pressure uses the captured location. Do not "fix" by delaying the wound past card order.

5. **Success pick** — HD state `03054` character pick; wound target then move Home (`engage=false`). No Pass when targets exist (mandatory "target"). If pressure succeeds but no opposing left, notify + `createActionResolvedEvent`. Failure path also resolves the action (mirror `Action_03040` / `Action_03cd20`, not the incomplete `Action_01105` failure gap).

6. **Move after wound on target** — BeingWounded defers actual Wounded; queued Move tends to run before Wounded applies, so they reach Home then take the wound. If lethal after move, destroy at Home — acceptable. Avoid queueing Move after a lethal wound that already sent them to locker (would yank locker→Home).
