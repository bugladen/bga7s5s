# Syrneth Compass (_03055) — create-faction-attachment

## Card text
**City Action:** Engage this card • Move the equipped character to a location where there is a **Scion** or an **Artifact**. *(The Artifact may be available or equipped.)*

No equip restriction. Traits: Artifact, Syrneth, Unique. WealthCost 0. Ussura faction attachment.

## Context
Continuing FAF Ussura after No Steel (_03054) / Curry Favor (_03053). Last session was scheme City Actions; this is Pattern C AttachmentAction + choose-location.

## Approach / WHY

### Shape
- Pattern C: `AttachmentAction` + `IHasActions` / `ActionTrait` on the card.
- City Action → gate `cardInCity` on equipped character (no AttachmentCityAction base; mirror `_01073` / `_01075` / `_02047`).
- Engage cost is **this card** (attachment), not the performer → `createCardEngagedEvent(..., $attachment->Id, ...)` like `Reaction_01022`.
- Move with `engage=false` — printed engage is the attachment cost only.

### Destination finding
Location is valid if (≠ current) and either:
1. Any character there (incl. uncontrolled) has trait Scion, OR
2. Available (unattached) Artifact at location via `getAvailableAttachmentsAtLocation`, OR
3. Equipped Artifact on a character at that location

Include Player Home — text says "a location", not "City location"; Scions (_03014 Kaspar, _03052) can be Home. JS must special-case Home like `03029_3` (`makeHomeEndcapMarkerSelectable`), not copy bare `03032`/`03045` city-only loop (03032 PHP allows Home but JS omits it — deliberate fix here).

Exclude current location — "move to" implies different place. Compass itself is an Artifact, so current location always has one; without exclude the action would always offer staying put.

### State
Mirror `State_highDramaPhase03045` + HD_EVENTS `"03055"` + faf JS triple. Constant `403055`.

### Alternatives considered
- Engage on `EventActionTriggered` before location pick (like Tabard pressure): rejected — pay cost when effect resolves with the move, single resolution step.
- City-only destinations: rejected — text not limited to city.
