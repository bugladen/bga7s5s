# Courageous (_03058)

## Card
Duelist City Action: Target opposing character • if their controller has more characters at this location than you → Combat challenge.
Gambling Maneuver: +1 Parry and +1 Thrust for each opposing character.

Ussura Risk, Wealth 1, R/P/T 0/2/2. Traits Virtue / Challenge / Heroic.
Fixed scaffold typo Name "Couragous" → "Courageous".

## WHY this shape
Composition of existing patterns, not a new lettered recipe:
- City Action = Pattern A / Arrogant (`Action_03008`) shared challenge chooser + `NORMAL_CHALLENGE_TYPE` (no refuse/intervene side effects, no engage cost → keep auto-engage).
- Duelist gate = performer `hasTrait("Duelist")` like `Action_02061` — NOT Sorcerer.
- Headcount "If" = target filter (strict `>`), same discipline as Astute's bullet-If: only legal targets satisfy the condition. "You" = performer's controller count at location via `getCharactersAtLocationByPlayerId`.
- Maneuver = Gambling (`DUEL_GAMBLED`) + pure calc. Count opposing at **actor location**, ControllerId != 0. WHY location not global: duel maneuvers scale off the fight board; printed text omits "at this location" but pairing with the City Action's location headcount + `Maneuver_01031`/`_03011` location idiom fits. Ren-style global (`getCharactersInPlayByPlayerId`) would balloon Parry/Thrust. If Eddie says global, swap the count helper.

No custom CHALLENGE_TYPE, no new GameState/JS, no Risk-class handleEvent.
