# Card Text Audit: Grand Merchant Anghos (02021)

## Card Text

> **City Reaction:** When discarding cards to pay costs • One of your attachments discarded this way gains Wealth. *(This card counts as two when discarded to pay costs. Send it to The Locker after paying costs.)*
>
> **Technique:** If Grand Merchant Anghos has more [inf] than the adversary • +1[parry].

## Technique_02021: Pass

- Condition: `$anghos->Influence > $adversary->Influence` — strict greater-than, matches "more [inf] than"
- Effect: `$event->parry += 1` — matches "+1[parry]"
- Gets Anghos via `getOwningCharacter()`, adversary via `getDuelRoundOpponent()` — both correct
- Availability gated on condition, bonus applied in `EventDuelCalculateTechniqueValues`

No issues.

## Reaction_02021: One Fix

Everything lines up with the card text:
- City check via `cardInCity()`
- Triggers on `EventEnteringPayState` (before payment so Wealth can affect validation)
- Player chooses attachment in hand → `addTrait('Wealth')`
- When that attachment is discarded as payment → queues Locker event
- Cleanup at `EventPlayerTurnEnd` removes Wealth if attachment still in hand

### Fix: Missing Null Check

`getOwningCard()` returns `?Card`. Line 76 accessed `$owner->IsUpdated` without null check, but the same pattern on line 88 had one. Added `if ($owner)` guard to match.

## Notes on Design Choices

- `setUsed(true)` is called even when the player declines. This means they get one shot per day. This is reasonable for a City Reaction — the player is prompted once and must decide.
- `EventPlayerTurnEnd` cleanup fires for ANY player's turn end (doesn't check `$event->playerId`), but since the reaction only fires during the controller's turn, the controller's turn-end always comes first. Not a problem.
- If the attachment is discarded for a reason other than payment (e.g., another effect), Wealth trait won't be cleaned up until `EventPlayerTurnEnd`. If the card isn't in hand by then, Wealth persists wherever the card is. Harmless — Wealth only matters in hand during payment.
