# Giacinto _04032

Finished BAS character: global opposing-Sorcerer Influence debuff + 3-step En Garde City Action.

## Abilities

1. **Passive** — Opposing Sorcerers have -1 Influence while Giacinto is in play.
2. **En Garde City Action** — Target opposing character at Giacinto's location → opponent may discard to prevent → else pick adjacent City location and move both.

## Decisions

**Passive mirrors Contempt and Hatred (`_01143`) for apply/remove/condition/notif** — but scope is **location-based "opposing"** (same spot as Giacinto), not global. `getOpposingSorcerersAtLocation` with EventCardMoved stale-DB compensation (Benci `_04001` / Axelle `_04022`).

**Home = no aura** — `LOCATION_PLAYER_HOME` is shared; `getCharactersAtLocation(HOME)` would treat every player's Home as one spot. Return empty opposing list at Home; clear on Giacinto move-to-Home; skip recruit/muster hooks while Giacinto is at Home.

**Action flow = Crimson Roger (`02036a`) + Depose move-both (`04028`)** — step 1 target, step 2 opponent hand discard or Pass (`createTransitionEvent` to swap active player), step 3 adjacent city location picker (`getAdjacentCityLocations`, not controlled-location list). Both moves `engage=false`, shared `batchId`.

**En Garde = `!$giacinto->Engaged`** in `isAvailableToPlayer` only — not an Engage cost on the move.

**states.inc.php** registers `04032`, `04032_2`, `04032_3` for transition-event player handoffs; `_3` location step stays on Giacinto's controller.

**04032_2 transitions** — single `""` → EVENTS for both pass and reveal (02036_2 shape). Duplicate `"pass"` key caused BGA "More than one possible transition" — fixed earlier. **Do not** add a direct `"revealed"` → `_4` transition on `_2`; multi-ack states in this codebase always enter via `createTransitionEvent` + `nextState("")` through EVENTS (04005_2, 04018_2, 01192, 03043). Direct `nextState("revealed")` logged hand cards but never entered `highDramaPhase04032_4`.

**Hand reveal flow** — `_2`: Reveal Hand **or** Pass. Reveal → `"04032_4"` (ACTIVE_PLAYER for Giacinto + chooseList) → Ok → `_6` bridge (active = hand owner) → `_5` discard. Pass → `"04032_3"` → location move.

**Not multiplayer** — User clarified: Giacinto must see revealed cards in chooseList, not a multi-ack round. Multi-ack left immediately (auto-ack pref / zombies). `_4` is now single activeplayer for Giacinto's controller; chooseList always stays until they Ok.

**Availability** requires opposing target at location AND ≥1 adjacent city location — otherwise action is greyed (can't complete the "move both" half).
