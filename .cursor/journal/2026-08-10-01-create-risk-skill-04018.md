# create-risk skill update — Seek Each Devil (_04018)

## Why

Eddie asked to capture `_04018` learnings into create-risk. Without this, a future agent would likely:
1. Treat "Target an enemy at an adjacent City location" as B.1 location chooser (wrong — printed Target → character chooser + Cesca)
2. Invent sequential single-active states to "pass the turn" for each discarder (wrong — BGA `MULTIPLE_ACTIVE_PLAYER` + `setPlayersMultiactive` makes them concurrent)
3. Put Academic/Hunter −1 cost on a fabricated Maneuver so combat-card pay also discounts (wrong — E.2 Action-only; combat-card stays full WealthCost)
4. Treat En Garde as an Engage cost
5. Grey the Action when no Sorcerer/Monster controllers will discard (move is primary; empty discard list just notifies + skips `_2`)
6. Queue discard Transition before ActionResolved and leave HD action hanging

## What was added

1. **Pattern B.5** in `pattern-b.md` — Target adjacent enemy → move `engage=false` → sticky `$PlayersToDiscard` + multi-active discard; contrast table vs B.1 / B.3
2. **Pattern E.2** expanded for performer-trait discounts (`Academic`/`Hunter`) + null-check `$performer`
3. **Shape table / Finish / compose / description** triggers — Seek Each Devil phrases
4. **checklist item 56** + E.2 item 48 expanded; references `_04018` row
5. **wiring.md** — multi-player hand discard JS/state seat
6. **helpers.md** — `getAdjacentCityLocations`, multiactive APIs, `createCardDiscardedFromHandEvent`, ActionResolved-before-Transition note

## Feelings

B.5 is mostly Taunt's Target shape flipped (you move, not them) plus Denounced's multi-discard seat. The valuable WHYs are (1) Target character ≠ B.1 location, (2) multi-active ≠ turn passing, (3) performer-trait E.2 not Leader-only, (4) ActionResolved before trailing discard Transition.
