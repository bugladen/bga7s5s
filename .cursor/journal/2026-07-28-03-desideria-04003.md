# Desideria Colomberia _04003

## Text

1. **En Garde City Reaction:** After your Thug at this location is destroyed during a duel or by an opponent's effect, wound Desideria • Put the Thug in your hand.
2. **City Reaction:** After Desideria performs a Sorcerer ability, wound her • Draw a card.

## Classification

Both Pattern D button Reactions. Split `Reaction_04003a` / `Reaction_04003b` (Odette `_03027` shape). No states / no JS.

## WHY decisions

**En Garde = `!$owner->Engaged` precondition:** Same as Tijani `_04cd29` En Garde City Action — not an Engage cost. Gate at trigger.

**Cause gate (duel OR opponent effect):** `EventCharacterDestroyed` has no `sourceId`. Wound-path destructions: mark `$opponentLethalThugId` on `EventCharacterWounded` when the wound would kill (`Wounds + event.wounds >= ModifiedResolve + WoundsHealedIncoming`) and `source.ControllerId` is a live opponent. Destroyed then qualifies if `IN_DUEL` OR id matches the mark. Direct destroys during a duel (e.g. Dante `Maneuver_01031`) ride the `IN_DUEL` arm. Crew Cap / Dawn / self-wound outside duel do not qualify.

**Location on Destroyed:** `runEventHubAfterCards = true` — `$destroyed->Location` still city during `handleEvent` (Odette `Reaction_03027a`).

**Hand return after EventHub:** Destroy reinjects a fresh card into locker (or discard if Brute). Recover = `RemovedFromLocker`/`RemovedFromDiscard` + `AddedToHand` (02032 / discard-notif sibling).

**Hand return is immediate (no DuelEnd defer):** Considered Object of Wonder `Reaction_01202` deferral, but locker cards are **not** loaded by `Theah::buildCity`, so a pending recover on Desideria/Thug would miss across requests (and Desideria's wound cost can kill her / reinject her). Attachment-based 01202 can defer because the attachment stays in play. Immediate `RemovedFromLocker|Discard` + `AddedToHand` instead. Brute path → discard; others → locker.

**Reaction b not `ISorcererAbility`:** Printed "City Reaction", not "Sorcerer City Reaction". Cesca `Reaction_03001` / Elina `Reaction_01118` shape — avoids self-retrigger loop from the wound. Identity: `sourceId == owner || performerId == owner`.

**Pass before setUsed** on both — daily slot survives decline.

## Playtest bug: mid-duel hand return ended the duel (2026-07-28)

Eddie: Thug died Round 1 with leftover adversary threat (3); Desideria recovered Thug into hand immediately; duel ended instead of Round 2.

**Root cause:** `stDuelNextPlayer` only preserves threat when the dead participant is still in `Locker-`/`Discard-`. Moving to Hand made `!$actorIsDead && locations differ` → nullify remaining threat → both pools 0 → `endOfDuel`.

**Fix:** During `IN_DUEL`, stash thug id in per-player global and leave them in Locker/Discard. `stDuelEnd` calls `Reaction_04003a::flushPendingRecovers()` after clearing `IN_DUEL`. Outside duel, still immediate. (User said 04003b — that was 04003a, the Thug-destroy reaction.)
