# No Rest for the Wicked (_04025) implementation

## Classification
1. Pattern A resolve: Add City Card to Bazaar (`createCityCardAddedToLocationEvent` like Midnight Shipment `_01149`), Then Renown to a **different** location (exclude Bazaar) — same pick shape as Forged for Battle `_04014` with `locationIds` + `actFromCardWithLocations`.
2. **Merchant Reaction** at end of Planning: `EventPhasePlanningEnd` + scheme at Home + ≥1 controlled Merchant + ≥1 drawable. Look/Pass buttons → private chooseList draw 2 / sink rest under `PLANNING_PHASE_END_EVENTS` (not Forced map — it's a Reaction). Yevgeni `_03052` / Decipher `_02005` / Otto `_01038` siblings for look/draw/sink.

## WHY decisions

### City card then Renown pick
Printed order. MEDIUM_PRIORITY transition so city-card event resolves before location pick. Guard empty city deck+discard (notify, still offer Renown) — `_01149` indexes `[0]` unsafely. "Different location" still means ≠ Bazaar even if no card was added.

### Merchant Reaction (not Forced)
Printed keyword is Reaction → Look/Pass offer via `createReactionTransitionEvent`, then pick state under `PLANNING_PHASE_END_EVENTS` with key `"04025"` (same string also on resolve map — intentional, like `_01098`). 4th arg = reaction Id so `actFromCardWithIds` routes to Reaction.

### Merchant trait gate + look count
Trait-prefixed Reaction with no performer in trigger → need ≥1 controlled Merchant (`getCharactersInPlayByPlayerId`). Look = 3 + merchantCount (always ≥4 when offered). Pass does not `setUsed`; Look does.

### Private look + clamp draw
"Look at" ≠ Reveal — `argsForStatePrivate`. If looked ≤2, auto-draw all / skip pick (cannot draw two of one). If >2, exact-2 multi-select. Sink = bottom of faction deck (`createCardAddedToFactionDeckEvent(..., false)`). Draw = remove-signal + `createCardAddedToHandEvent` (Otto).
