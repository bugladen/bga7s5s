# Danilo Danini _04002

## Text

1. Passive: Your Thugs at Home and Danilo's location gain +1 Finesse and +1 Resolve.
2. City Action: Engage Danilo • Influence challenge to target opposing. If another character intervenes, wound them or draw a card.

## WHY decisions

**Aura = tracked id set, not Technique grant:** Jean-style Technique aura doesn't fit — we need Finesse+Resolve stat buffs. Track `$BuffedThugIds` on Danilo; sync apply/remove on location/muster/approach/destroy/recruit. Finesse via `createCharacterFinesseModifedEvent`; Resolve via direct `ModifiedResolve ±1` (no factory — Joern).

**Home is always in the aura scope:** Text is "at Home and Danilo's location" — Home Thugs always get the buff even when Danilo is in the city. When Danilo is at Home, locations collapse (no double-apply — set membership).

**Home lookup:** `getCharactersAtHomeByPlayerId` only — never `getCharactersAtLocation(HOME)` (shared string across players; Benci lesson).

**EventCardMoved stale DB:** same Angeline exclude-out / include-in when computing each Thug's effective location and Danilo's effective location.

**DANILO_CHALLENGE_TYPE = 25:** needed to key the intervene follow-up (Cornered shape). Engage printed → trichotomy (a) → add to stIssueChallenge auto-engage list. No intervene/refuse restrictions → no Theah/args/JS Refuse wiring beyond the JS int.

**Intervene choice via GENERATE_THREAT_EVENTS:** Intervene queues events then proceeds to GENERATE_THREAT → EVENTS. Intervened is processed there; queue `createTransitionEvent("04002_3")` and map that transition on GENERATE_THREAT_EVENTS. After Wound/Draw, return to GENERATE_THREAT_EVENTS so remaining queue (incl. GenerateThreat if Transition somehow interleaved — Transition priority 8 runs after medium) finishes → RESOLUTION.

**Pattern F picker "04002" / "04002_2":** standard Aja/Sanjay. `_2` → TECHNIQUE_AVAILABLE. Choice is `_3` so it doesn't collide.

**IAbilityThatTargetsCharacters:** text says "target opposing character" — yes.
