# Sabre `_04054`

## Context
Continuing BAS Neutral attachments after Leather Spaulders `_04053`. Sabre is a Weapon/Melee/Sword with two printed Techniques and no equip restriction.

## Classification
1. `<b>Technique:</b> +1[Thrust]` → Pattern E — plain free Technique. Inline `Technique_PlusOneThrust` + `setId` on the card (handles duel Calculate + challenge GenerateThreat).
2. `<b>Technique:</b> Engage this card • +1[Riposte]` → Pattern E — engage-cost duel Technique. Same availability/Resolve as Pompon `Technique_04026`; Calculate `riposte += 1` instead of parry.

## Mirror choice / WHY
- Free +1 Thrust: instantiate `Technique_PlusOneThrust` on the card with `setId('Technique_04054a')` (Rapier `_01074` / Millstone `_04cd14`). No card-specific subclass — the wrapper only re-declared Name and the Canceled comment already on the base.
- Engage + Riposte still needs `Technique_04054b` — engage cost is not on PlusOneRiposte. Copy `Technique_04026` (IN_DUEL + !Engaged + actor==owner); Calculate `riposte += 1`. WHY Riposte is duel-only: no challenge equivalent (unlike Thrust→threat). Do not add GenerateChallengeThreat. Do not add DUEL_GAMBLED.
- Considered extending `Technique_PlusOneRiposte` for b and only adding engage — rejected because PlusOneRiposte already has its own isAvailableToPlayer/handleEvent without engage; cleaner to own the full engage shape like 04026.
