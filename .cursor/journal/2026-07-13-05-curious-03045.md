## Approach / WHY

### Action — Pattern B.1
Mirror Follow the Thread (`Action_03009`) for the location-chooser sub-state, Bloody Entrance (`Action_03032`) for wound-then-move on confirm.

**Not City Action** — skill is emphatic: plain "Action:" keeps home performers. Start from `parent::getPerformersForAction`, filter by valid destinations only. No Sorcerer.

**"Controlled by an opponent"** ≠ "enemy character at location" (`03009`). Use claim control:
```
$controller = getControllerForLocation($location);
$controller != 0 && $controller != performer->ControllerId
```
WHY exclude 0: uncontrolled city locations aren't "controlled by an opponent."
WHY `includeHome=false`: Home isn't claim-controlled; Pattern B.1 says don't admit Home unless text does.

Wound + move both `eventCheck` before queue, same as 03032. Resolve on location confirm (no Pass on state — must pick).

No `IRiskThatTargetsCharacters` — location pick, not character chooser. Same as `_03009`/`_03032`.

### Gambling Maneuver
`DUEL_GAMBLED` gate only (no Influence compare — text has none).
- Calc: `+2 Riposte`
- Resolve: wound `getDuelRoundActor()` (participant), with `eventCheck`
Shape is Maneuver_02018 (wound self + calc bonus) + 03008 Gambling gate. Not 03033 (that wounds adversary).
