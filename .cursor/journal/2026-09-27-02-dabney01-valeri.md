## BGA rule: empty transition
**An empty transition key `""` may only exist if it is the sole transition from that state.** If the state also has `"back"` (or any other named transition), success must be a named key (`"done"`, `"characterChosen"`, etc.) and callers must `nextState("thatName")`. Bare `nextState()` / `nextState("")` is only OK when `""` is alone.
